# 🛍️ Online Store Management System

A simple Online Store Management System built using Python to manage products, shopping cart, and orders.

## 🚀 Features

* Display available products
* Add products to cart
* View shopping cart
* Calculate total price
* Manage customer orders
* Simple and user-friendly menu

## 🛠️ Concepts Used

* Python
* Variables
* Lists
* Dictionaries
* Functions
* Conditional Statements
* Loops
* User Input

## ▶️ How to Run

Run the Python file using:

```bash
python "🛍️ Project 8 . Online Store Management System.py"
```
